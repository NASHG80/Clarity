# Database Module

This directory contains the canonical seed data, generators, validators, and reset scripts for the Green & Inclusive Travel MongoDB database.

## Demo Reset (`reset_demo_data.py`)

A deterministic hackathon rehearsal reset script that targets explicitly demo-generated state while preserving all researched seed records.

**What it resets:**
- Any demo analytics generated by D9 (identifiable via `biz_001`/`biz_002`/`biz_003` or `demo_evt_`).
- Any `ai_inspections` recorded for demo businesses during integration tests.

**What it preserves:**
- All real canonical seed data across all collections (hotels, routes, experiences, businesses, confirmations).
- The single canonical `demo_synthetic` hotel fallback record.
- Any non-demo `ai_inspections` or `analytics_events` deliberately excluded from the `biz_001`/`biz_002`/`biz_003` cleanup boundary.

### Commands

**Dry Run:**
See what records the script intends to remove without mutating MongoDB.
```bash
python database/reset_demo_data.py --dry-run
```

**Full Reset:**
Connects to MongoDB, deletes ONLY demo-generated artifacts, strictly upserts the canonical seed data (`seed.py`), and regenerates the canonical demo funnel (`generate_demo_analytics.py`).
```bash
python database/reset_demo_data.py
```

### Safety and Requirements
- **Mongo Connectivity:** The script strictly requires an active MongoDB connection via `MONGO_URI` / `MONGO_DB_NAME`.
- **Production Guard:** A native safety check aborts execution if the `MONGO_DB_NAME` suggests a `prod` target. NEVER point this script at a real production cluster.
- **Post-Reset Validation:** After running the script, verify integrity by invoking the read-only validators:
  ```bash
  python database/audit_data_state.py --source mongo
  python database/check_demo_analytics.py --source mongo
  python database/check_demo_synthetic.py --source mongo
  ```
